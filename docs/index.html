Snitch

Snitch is a tiny macOS menu bar app that shows which local processes are listening on ports, opens localhost quickly, and kills stuck services.

Download (Apple Silicon & Intel)

  • Direct DMG download: Snitch for macOS
  • All releases: GitHub Releases

Install

  1. Download the DMG above.
  2. Open it.
  3. Drag Snitch.app into Applications.
  4. Launch Snitch from Applications.

If you get stuck installing because it is not notarized by Apple (I do not have an Apple Dev account right now), go to System Settings then Privacy & Security and click Open Anyway. Use good judgment to decide if you trust me.

What Snitch does

  • Lives in your menu bar as a 🐀.
  • Friendly names like “Next.js · my-app”, with memory use per server.
  • Opens localhost in your browser, or your project in Finder or your editor.
  • Stops a server safely, including its npm run dev wrapper.
  • Warns when a server is visible on your Wi-Fi.
  • Native, about 1.5 MB, and light on RAM.

Updates

Snitch checks GitHub Releases once a day and tells you when a new version is available. Right-click the menu bar icon and choose Check for Updates… to check now, then drag the new app into Applications.
